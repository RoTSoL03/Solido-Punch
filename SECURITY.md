# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's **Security** tab to submit a private vulnerability report instead:

https://github.com/RoTSoL03/Solido-Punch/security/advisories/new

Include reproduction steps, the affected browser or environment, and the
potential impact. Reports will be acknowledged as soon as practical.
